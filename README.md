# memo-app-laravel
# 📝 メモアプリケーション - 変更内容一覧

本プロジェクトで実装・変更を行ったファイルおよびその機能の概要です。

---

##  1. routes/web.php（アプリケーションのルーティング）

### 変更・追加内容
* 認証必須（`middleware => ['auth']`）のルーティンググループを設定。
* メモ一覧画面表示ルートの追加: `GET /memo` (`memo.index`)
* メモ新規作成ルートの追加: `GET /memo/add` (`memo.add`)
* メモ更新処理ルートの追加: `POST /memo/update` (`memo.update`)
* メモ削除処理ルートの追加: `POST /memo/delete` (`memo.delete`)

### 実装された機能
メモ機能に関するすべてのリクエストを保護し、対応するコントローラーへ正確にルーティングすることで安全な処理を実現。

---

##  2. app/Http/Controllers/MemoController.php（ロジック処理）

### 各関数の追加・改修内容
* **`index(Request $request)`**: ログイン中ユーザー（`user_id`）のメモ一覧を更新日時の降順で取得。URLパラメータの `id` を基に選択されたメモ（`$select_memo`）の情報を読み込み。
* **`add()`**: 現在の `user_id` に紐づくデフォルト状態の新規メモを作成し、作成したメモの編集画面へ直接リダイレクト。
* **`update(Request $request)`**: 送信された `edit_id` と `user_id` に基づき、メモのタイトル（`edit_title`）および本文（`edit_content`）を更新。
* **`delete(Request $request)`**: 送信された `edit_id` に基づき、ログインユーザーが所有するメモをデータベースから削除。

### 実装された機能
CRUD（作成・読み出し・更新・削除）のビジネスロジック全般を処理し、他ユーザーのデータアクセスを防ぐデータセキュリティを確保。

---

##  3. resources/views/memo.blade.php（ユーザーインターフェース）

### 変更・追加内容
* Blade構文（`@forelse`）を使用して、左側サイドバーへ動的なメモ一覧を表示。
* 現在選択されているメモ（`$select_memo->id`）に対し、アクティブ状態（`active` クラス）を付与。
* 選択されたメモのタイトルおよび本文データを右側の編集フォームへ自動セット。
* 保存ボタン（Save）および削除ボタン（Delete：`formaction` と JavaScript の `confirm` 確認ダイアログを使用）用の POST フォームを設定。
* メモが選択されていない状態では、入力エリアおよび操作ボタンに `disabled` 属性を付与。

### 実装された機能
サイドバーとエディターを1画面にまとめたシームレスな操作感を提供し、リアルタイムでのデータ表示・更新に対応。
